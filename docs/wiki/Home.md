# ObjC Runtime Utilities

ObjC Runtime Utilities for Swift and SwiftUI wraps public Objective-C runtime features in small, documented Swift APIs.

## Core Modules

- `ObjCRuntimeUtilitiesObjC`: low-level Objective-C shim
- `ObjCRuntimeUtilities`: Swift API
- `ObjCRuntimeUtilitiesUI`: SwiftUI/UIKit adapters
- `runtime-inspector`: command line example
